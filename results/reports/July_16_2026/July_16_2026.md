# Report July 16th

Overall many performance improvements can be shown. It's clear that Async-IO has had a huge effect, which can be seen when comparing to main.
Power benchmarks have not yet been performed, but they will be.

All tables were written with DuckDB-Iceberg @ v1.5.4 to a glue catalog that does not have automatic compaction. This is to avoid any drastic performance differences in the middle of a benchmark.

##### With S3Tables providing compaction

The idea here is that s3tables now provides different physical parquet files. The engine is the same, but now s3tables has changed the backing parquet files, so we can see that there are even more performance gains to be made.
